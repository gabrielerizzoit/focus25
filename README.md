# Focus Flow

Create a simple, fast, SEO-optimized web app called Focus25.

## 🎯 Goal

A minimal, no-login online focus timer (Pomodoro-style) optimized for SEO and instant use.

---

## 🧠 Core UX (VERY IMPORTANT)

- Homepage = timer (no landing page, no friction)

- No account, no signup, no email

- Clean, minimal interface

- Works instantly on page load

---

## ⏱️ Timer Features

- Default:

  - Focus: 25 minutes

  - Short break: 5 minutes

  - Long break: 15 minutes

- Allow user to customize:

  - focus duration

  - break duration

- Start / Pause / Reset buttons

- Auto-switch between focus and break (toggle ON/OFF)

- Visual countdown (large centered timer)

- Subtle progress ring animation

---

## 🔊 Sound & Music (FREE ONLY)

- Add background study music (royalty-free):

  - rain

  - cafe

  - white noise

- Toggle ON/OFF

- Volume control (simple slider)

- Add countdown alert sound in last 5 seconds

- Final sound when session ends
